# DevOps Lab Exercises

This repository contains the implementation of 10 DevOps lab exercises covering Kubernetes, Docker, container security, monitoring, and Jenkins CI/CD pipelines.

## Exercises

### Exercise 1: Kubernetes Hello Pod
Created and deployed a Kubernetes Pod and Service using Minikube.

### Exercise 2: Multi-Node Kubernetes Cluster
Deployed Product Catalog and Shopping Cart Flask applications on a three-node Minikube cluster using Deployments, ReplicaSets, pod anti-affinity, and NodePort Services.

### Exercise 3: Flask Application on Kubernetes
Containerized and deployed a Flask application on Kubernetes, with verification of the application deployment and service.

### Exercise 4: Flash Sale ReplicaSet Scaling
Implemented a Kubernetes ReplicaSet-based flash sale application and explored replica scaling to manage application availability.

### Exercise 5: Docker Networking
Explored Docker networking concepts and configured container communication using Docker networks.

### Exercise 6: Docker AppArmor Security
Explored container security using Docker and AppArmor, documenting the environment limitations encountered during enforcement testing.

### Exercise 7: Real-Time Monitoring and Alerting
Implemented a real-time monitoring and alerting exercise to observe system or application metrics and identify conditions that require attention.

### Exercise 8: Jenkins Continuous Integration
Created a Jenkins CI pipeline to install dependencies and run automated Python unit tests, verifying the build result through Jenkins.

### Exercise 9: Hello World Jenkins Job
Created and executed a Jenkins Freestyle job to print `Hello, Jenkins!` and verified successful execution using the console output.

### Exercise 10: Jenkins Multi-Stage Pipeline
Built a Jenkins pipeline for a Python Flask application with five stages: Build, Test, Deploy, Run Application, and Test Application. Added automated unit testing and application startup verification.
