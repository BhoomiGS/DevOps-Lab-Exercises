# Exercise 10: Jenkins Multi-Stage Pipeline

## Objective
Automate the build, testing, deployment, and startup of a Python Flask application using Jenkins.

## Technologies
- Jenkins Pipeline
- Python
- Flask
- Git and GitHub
- Python unittest

## Pipeline Stages
1. Build: Create a virtual environment and install Flask.
2. Test: Run unit tests.
3. Deploy: Copy the application into a mock deployment directory.
4. Run Application: Start the Flask application.
5. Test Application: Verify the application startup log.

## Expected Result
All five pipeline stages should complete successfully.
